# TECHD - Criação de Sites e Soluções Tecnológicas

## 1. Objetivo e Finalidade
Website institucional e comercial da TECHD para atração de clientes interessados em criação de sites, sistemas web e presença digital.

## 2. Tecnologias Utilizadas
- HTML5, CSS3, JavaScript Vanilla, Responsive Design

## 3. Arquitetura e Estrutura de Diretórios
Website estático direto com código enxuto, assets otimizados em `assets/` e estrutura focada em alta conversão de clientes.

## 4. Principais Arquivos e Responsabilidades
- `index.html`: Página principal com apresentação de portfólio, serviços e contato.
- `assets/`: Imagens, logotipos e folhas de estilo.

## 5. Funcionalidades Identificadas
- Seções de serviços de desenvolvimento e marketing digital
- Botões de chamada para ação direcionados para o WhatsApp comercial
- Design leve e responsivo para visualização rápida em mobile

## 6. Como Compilar ou Executar
```bash
python3 -m http.server 8080
```

**Completo**
